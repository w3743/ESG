# 可持续发展治理

## 可持续发展治理体系

我们致力于将可持续发展理念深度融入集团的生产运营之中，不断完善并优化可持续发展治理体系，搭建跨部门工作机制，以确保可持续发展工作能够得到全面、有效落实。集团党委、董事会是可持续发展工作的最高决策机构，负责可持续发展战略规划、年度计划的审议工作，同时负责审核集团年度可持续发展（ESG）报告；董事会办公室负责制定可持续发展工作的具体实施规划，组织编制年度可持续发展（ESG）报告；在各职能部门及下属企业设置可持续发展工作联系人，负责具体可持续发展工作的落实，并定期整理、收集可持续发展相关资料与数据，协助年度可持续发展（ESG）报告的编制。
