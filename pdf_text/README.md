# ESG parsed text

This directory contains parsed report text and source manifests only. Original
PDFs, MinerU structural JSON, images, layout artifacts, archives, training data,
logs, and temporary files are not published here.

Each report uses `pdf_text/batch-<NN>/<ticker>/` and contains only `report.md`
and `manifest.json`. A batch is published only after its 50-report validation
passes.
